# Glossary

| Term | Meaning |
|---|---|
| **B2B** | A sale to a GST-registered business. |
| **B2CL** | A large inter-state sale to an unregistered buyer. |
| **B2CS** | Any other sale to an unregistered buyer. |
| **BOM (bill of materials)** | The components needed to make one unit of a product. |
| **CGST, SGST** | Central and state GST, charged on sales within a state. Each is half the rate. |
| **COGS** | Cost of goods sold: net units sold × cost per unit. |
| **Credit note** | A document that reduces what a customer owes, after an invoice was issued. |
| **Debit note** | How the app records a credit note received from a supplier. |
| **Dr, Cr** | Debit and credit. On a ledger, Dr means they owe you and Cr means you owe them. |
| **E-way bill** | A government document for moving goods above a value limit. |
| **Financial year (FY)** | 1 April to 31 March. |
| **GSTIN** | The 15-character GST number. The first two digits are the state code. |
| **GSTR-1** | The monthly or quarterly return of your sales. |
| **GSTR-2B** | The portal's statement of input credit available, based on suppliers' filings. |
| **GSTR-3B** | The summary return where you pay your tax. |
| **HSN, SAC** | Codes for goods (HSN) and services (SAC). |
| **IGST** | Integrated GST, charged on sales between states. |
| **IMEI** | A phone's unique identifier. The app treats it as a serial number. |
| **ITC (input tax credit)** | GST paid on purchases that you can set against GST on sales. |
| **Ledger** | The account for a customer or supplier. |
| **MCP** | Model Context Protocol, the standard AI assistants use to connect to apps. |
| **Place of supply** | The state a sale counts as made in. It decides CGST + SGST or IGST. |
| **Proforma invoice** | An invoice-style offer, not a tax invoice. It has no effect on your books. |
| **Receipt** | Money you received. |
| **Set-off** | Using input tax credit to pay the GST you owe. |
| **SKU** | Your own code for a product. |
| **SMTP** | The standard for sending email. |
| **Voucher** | Any accounting entry: invoice, receipt, payment or credit note. |
